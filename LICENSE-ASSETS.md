# Asset licenses

All art used by opencode-pixel is original work created for this project. Nothing from other
pixel-office projects, commercial tilesets or asset packs is copied into this repository.

| Asset | Source | License | Notes |
| ----- | ------ | ------- | ----- |
| `web/art/palette.js`, `color.js`, `draw.js` | Original, authored for opencode-pixel | MIT | Colour palette and pixel drawing helpers. |
| `web/art/characters.js` | Original, authored for opencode-pixel | MIT | Hand-authored 16×26 characters, eight looks, seven poses. |
| `web/art/props.js` | Original, authored for opencode-pixel | MIT | Desks, chairs, lounge, plants, kitchenette, cat, wall art. |
| `web/art/scene.js`, `web/renderer.js` | Original, authored for opencode-pixel | MIT | Room composition and canvas renderer. |
| Fonts | — | — | No font files are bundled. The HUD uses the host system's UI font stack. |
| Screenshots in `docs/` | Captured from this project | MIT | Generated from the bundled art and demo data. |

The visual direction is a warm, top-down night office, but every sprite, tile, prop and animation is
drawn in code in this repository.

If you add an external asset later, record the file/pack name, author, source URL, license and where it
is used here. Only assets compatible with redistribution under this project's MIT license may be
committed.
